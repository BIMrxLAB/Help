Member Management

Naviate Cloud Manager allows one or more members at a time to be assigned to one or more Autodesk® BIM 360® and/or Forma (formerly ACC) projects. These projects may be those recently added using Naviate Cloud Manager or those already existing and in use. Additionally, Naviate Cloud Manager displays project access levels, services and roles and provides the ability to update existing project members.

Naviate Cloud Manager — Members Module

Members Overview

The Members module performs the following functions:

    • Displays all Hub members for the selected Hub.
    • Displays the Job number for the Project.
    • Displays all Project members for a selected Project.
    • Displays all Projects to which each member belongs.
    • Displays access levels, roles and other information for each member at both the Hub and Project level.
    • Displays all companies available for assignment to Project members.
    • Displays all roles available for assignment to Project members.
    • Imports selected Hub members to one or more selected Projects.
      • Allows assignment of a company, role, and Project Admin Access when importing Hub members to a one or more Projects.
    • Updates/removes company, roles and Project Admin Status for existing Project members.
    • Updates Hub member Status to Active or Inactive.
    • Updates Hub member Default Company.
    • Adds one or more new members to the selected Hub


For demonstration purposes, and to easier navigate the documentation, the Members Module is divided into three separate, but related, sections:


Section 1: The Project Section


The Project Section handles all project related operations;

  • Filter Projects
  • Selecting Projects
  • Cache Management of Projects
  • Project Display Information


Section 2: The Members Section


The Members Section handles the following member related operations:

  • Filtering Members
  • Selecting Members
  • Cache Management of Members
  • Member Display Information
  • Hub Member Management


Section 3: The Project Member Management Section


The Project Member Management Section handles the following operations:

  • Updating Project Members
  • Adding Project Members
  • Removing Project Members (applicable to Forma/ACC only)
  • ACC Product Access Template Management
  • Company and Role selection for assignment to project members
