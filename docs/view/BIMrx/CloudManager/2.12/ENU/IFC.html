IFC

IFC allows the user to export IFC files from a selected Revit� model. The user is able to choose either a specific IFC Export Setup or a filter that selects export setups by name, filter the views to be exported, and specify the location to which the files will be saved. Each model has its own folder created in the specified Export Folder Location. The user also has the ability to specify the Revit� Year Version via the dropdown selection.

With IFC selected, press the Modify Export Settings button to the right of the Export Type field to bring up the Export IFC Configuration Settings dialog window.

IFC Export Setup

There are two ways to designate which IFC Export Setup will be used:

  • IFC Export Setup � Enter the name of a single export setup defined in the model.
  • Filter IFC Export Setup � Enter filter text to select export setups by name. When selected, the Contains checkbox and the Start With/End With toggle become available to refine how the filter text is matched.

View Name Filter

The View Name Filter allows the user to filter select the views in the model that are to be exported. As with the export setup filter, the Contains checkbox and Start With/End With toggle can be used to refine how the filter text is matched.

Space Boundary Level

Space Boundary Level specifies the level of space boundary information to be included in the exported IFC file.

Export Folder Location

Export Folder Location makes it possible to specify the location for the files to be saved. Press the folder button to the right of the field to navigate to and select the desired folder.

Revit� Year Version

Revit� Year Version allows the user to specify which version of Revit� to use for the export process.

Additional Options

  • Split wall and column elements at levels � When checked, walls and columns are split at each level in the exported file. If left unchecked, they will not be split.
  • Current View, export only the visible elements in the view � When checked, only the elements visible in the view are exported. Leaving this box unchecked will export the entire model.

When editing is complete, press Save or Cancel. These settings can be modified at any time prior to deploying the job. Once the job has been deployed, however, they cannot be changed. To change the settings, the job will first need to be un-deployed; the settings changed and saved; then the job can be redeployed.

Important � If a required entry is missing or invalid when Save is pressed, a Warning message will be displayed listing the items that need to be corrected.
