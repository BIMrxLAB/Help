Naviate Logout

The user can logout at any time from Naviate Cloud Manager by pressing the Naviate Logout button, located on the About Box.

Pressing the Naviate Logout button, as shown above, logs the user out from their Symetri License session. 

Once the Naviate Logout button has been pressed, a confirmation dialog appears, as shown on the following screen:  

Pressing the confirmation dialog shown above logs the user out from their Symetri License logon and closes the application. This means that for multi-user licenses, their license is returned to the license pool where it can be used by someone else. This is as opposed to when the user simply exits Naviate Cloud Manager, which does not release the license usage.

When the user exits from Naviate Cloud Manager in the usual way, without performing a Naviate Logout, the license display is unchanged, as shown below:

 

However, after pressing Naviate Logout, the license usage is decreased by 1, as shown below:

In practice, you will generally want to use Naviate Logout when it is either necessary to perform a Symetri Login as a different user; or possibly when it is necessary to free your license for use by someone else. Please refer to License Portal for more information on using the Symetri License Portal.

Tip — Use the Naviate Logout functionality either when it is necessary to login with different credentials, or when it is necessary to free a license and return it to the multi-user license pool.
