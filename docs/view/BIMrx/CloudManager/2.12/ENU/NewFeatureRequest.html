New Feature Request

Because Symetri is firmly committed to both the quality of Naviate Cloud Manager and to the satisfaction of it's customers, we have provided the ability for users to interact directly with the product team, and to participate in the feature development process. 

The New Feature Request link provides the user access to a website designed and maintained for the express purpose of tracking new product feature suggestions and improvement requests.

When entering the site, first look to see if the idea you have in mind is already listed. The number of votes given by other users for each idea has is clearly stated in the idea display. If your idea is listed, then click on for more options.

 

You can now enter your own details, thoughts, ideas and suggestions. Most importantly, vote for the feature by pressing the Vote button. The number of votes a suggestion receives is an important factor used by the product team in determining whether to incorporate a new feature, as well as its priority. 

Finally, you may want to press the idea Subscribe button.

Once subscribed, you will be notified regarding any changes to the idea information or status.  

Also, please note the change to the button label and the explanatory comment below it. The button now becomes an Unsubscribe button which allows you to easily cease receiving notifications for the request.

Finally, if the new feature you have in mind doesn't already exist, go ahead and add a new one.

Press the Add a new idea button from the main screen to bring up the following form.

Since we are dealing with Naviate Cloud Manager, select Naviate Cloud for the Idea workspace as shown above.

With the workspace selected, the following fields appear:

 

Go ahead and fill in the the idea summary and any additional descriptive details. Keep in mind you are communicating with both the Naviate Cloud Manager product team and user community.

The last piece of data is to assign a category for the idea.

If the idea doesn't fit neatly into one of the listed categories, go ahead and assign it to Feature Request.

The final step is to save the new idea by pressing the Share Idea button. Your idea is now available to the Naviate Cloud Manager community, including the product team. Check back regularly or read messages via a subscription to follow progress with the idea.
