Dialog Windows and Messages

While working in the Scheduled Jobs module, Naviate Cloud Manager displays a number of dialog windows and messages. Dialog windows are used to enter additional settings, while messages ask for confirmation before an action is taken or explain why an action cannot be completed. The following describes each of them and what to do when they appear.

Dialog Windows

Task Scheduler

Displayed when a job is added to, or removed from, the Windows Task Scheduler. It shows the Job Name, Job Type, Schedule Type, and Connection or Hub for the selected job.

When adding a job, select the server in the Deploy to Server drop down box, then press Add. Press Cancel to close the dialog window without making any changes. For more information, refer to Add Job as a Scheduled Task and Remove a Job from the Task Scheduler.

Token Refresh Task Scheduler

Displayed the first time a job using an Autodesk connection is deployed to a server, when a Token Refresh job for that server and user does not yet exist.

Select the Schedule Day and Run At Time for the Token Refresh job, then press Add. A Schedule Day must be selected; otherwise a message is displayed asking you to pick a day. For more information, refer to Token Refresh Jobs.

Copy Job

Displayed when the Copy button is pressed. It shows the Copy From Job Name and Copy From Description.

Enter a unique New Job Name, then press Copy. Press Cancel to close the dialog window without creating a new job. For more information, refer to Copy a Job.

Download Settings

Displayed when the Modify Download Settings button is pressed for a Download job. For more information, refer to Download Settings.

Export Configuration Settings

Displayed when the Modify Export Settings button is pressed for an Export job. A separate dialog window is displayed for each Export Type: Export PDF Configuration Settings, Export NWC Configuration Settings, Export DWG Configuration Settings, and Export IFC Configuration Settings. For more information, refer to Export Type.

Email Configuration

Displayed when the Email Configuration button is pressed. For more information, refer to Email Configuration.

Jobs Module Settings

Displayed when the Settings button in the Job Listing toolbar is pressed. For more information, refer to Jobs Module Settings.

Folder Selection

Displayed when the folder button next to a location field is pressed, such as the Download Files/Upload Repo Location or an Export Folder Location. Navigate to the desired folder and press Select Folder. The selected location is then entered into the field.

Confirmation Messages

The following messages ask you to confirm an action before it is taken. Press Yes to continue. Press No or Cancel to stop the action; a message confirming that the action was cancelled is then displayed.

Action

Message

Run a deployed job

Run Job: [Job Name] from Task Scheduler now? For Export jobs, the message also notes that the task will only run when the device is connected to AC power.

Stop a running job

Stop Job: [Job Name] now?

Delete a job

Delete Job: [Job Name]

Reactivate a Token Refresh job

Reactivate Job Refresh Token for: [Job Name] now? Your Autodesk login password will be required.

Deploy an Upload job with no project filter

An Upload project filter has not been selected--all files for all projects will be uploaded. Continue?

Deploy a Download job with no project filter

A Download projects filter has not been entered. All projects will be downloaded. Continue?

For more information, refer to Run Deployed Job, Stop Running Job, Delete a Job, and Reactivate Token Refresh Job.

Validation Messages

The following messages explain why an action cannot be completed. Correct the condition described, then try the action again.

Message Title

Cause and Resolution

Job Connection not assigned

A valid connection has not been assigned to the job. Assign a connection and try again.

Job Connection no longer available

The custom connection assigned to the job has been removed. Assign another connection and try again.

Job Hub no longer available

The hub assigned to the job is no longer available. Assign another hub and try again.

AD Login is required

You must be logged on with an Autodesk login to deploy a job that uses an Autodesk connection. Log in again with an Autodesk login and try again.

Assigned User must deploy the job

The Autodesk login assigned to the job does not match the current user. Either change the job to the current user, or have the assigned user deploy the job.

Upload Files Not Defined

A Static Upload job has no projects or files selected. Select at least one before deploying the job.

Schedule Windows Task

The network share on the remote server could not be accessed, or Naviate Cloud Manager is not installed on the remote server. Verify the server definition and installation, then try again. For more information, refer to Remote Server Setup and Configuration.

Schedule Type has not been checked

The Schedule button was pressed before a Schedule Type was selected. Select a Schedule Type, then press Schedule again.
